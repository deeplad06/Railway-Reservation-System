# Railway Reservation System

## Overview
A simple educational frontend prototype for searching trains between sample source and destination stations.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Features
- Search trains by source and destination.
- Display matching train details.
- Display sample seat availability.
- Show a message when no trains are found.

## Project Structure
- `index.html`: Webpage structure
- `style.css`: Page styling
- `app.js`: Train data and search functionality
- `README.md`: Project documentation

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open `index.html` in a web browser.
3. Enter a source and destination.
4. Click **Search Trains**.

## Note
This is a demonstration project. It does not connect to Indian Railways or provide live train schedules, availability, payments, or ticket booking.
